# FerrisGrid Brand Story

FerrisGrid started with a simple idea: computers already show us everything we need - pixels, windows, buttons, text fields, menus - but they do not explain the screen in a language an autonomous agent can act on.

So Ferris, the Rustacean, built a grid.

Not a heavy, slow, over-engineered map. A fast one. A practical one. A grid that turns the messy visual world of the desktop into something precise: coordinates, frames, actions, and traces. Every screenshot becomes a working map. Every click becomes a coordinate. Every scroll, keypress, and mouse move becomes part of a repeatable trail.

The name **FerrisGrid** combines two ideas:

- **Ferris** represents Rust: fast, safe, reliable, and a little playful.
- **Grid** represents the core abstraction: the screen is transformed into a coordinate system that an LLM can reason over.

The product philosophy is:

> Give the machine eyes, give the model a map, and let Rust move fast.

FerrisGrid is the bridge between vision and action. It captures the screen, overlays structure, asks the LLM what should happen next, executes the step, records the trail, and repeats - fast enough to feel alive, but grounded enough to be debuggable.

## Tagline

**FerrisGrid: turn screens into coordinates, and coordinates into action.**

## Positioning

FerrisGrid is local-first visual computer control for autonomous agents. It makes desktop state legible to an LLM by pairing screenshots with deterministic coordinates, constrained action files, and durable local traces.

## Voice

- Practical over grandiose.
- Precise over magical.
- Fast, local, and debuggable.
- Rust-native without assuming the reader already knows Rust.
