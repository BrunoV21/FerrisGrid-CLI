# Community

FerrisGrid development happens on GitHub.

## Open an issue

- [Bug report](https://github.com/BrunoV21/FerrisGrid-CLI/issues/new?template=bug_report.yml): crashes, incorrect output, platform-specific failures, or permission problems.
- [Feature request](https://github.com/BrunoV21/FerrisGrid-CLI/issues/new?template=feature_request.yml): new commands, backends, workflow improvements, or integration ideas.
- [Documentation fix](https://github.com/BrunoV21/FerrisGrid-CLI/issues/new?template=docs.yml): unclear instructions, stale examples, broken links, or missing setup details.
- [Question](https://github.com/BrunoV21/FerrisGrid-CLI/issues/new?template=question.yml): usage help, setup questions, or agent integration discussion.

TypeScript npm package bugs belong in [`BrunoV21/FerrisGrid-CLI-ts`](https://github.com/BrunoV21/FerrisGrid-CLI-ts), but feature requests and protocol changes should be opened here.
